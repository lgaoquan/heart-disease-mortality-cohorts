# Data access and permissions

This repository contains analysis code only. No individual-level data, source cohort files, restricted-use files or derived person-level datasets are included.

The manuscript used the following releases:

- **Health and Retirement Study (HRS):** RAND HRS Longitudinal File 2020 Version 1, Harmonized HRS Version D and Harmonized HRS End of Life Version B.
- **English Longitudinal Study of Ageing (ELSA):** Harmonized ELSA Version H and Harmonized ELSA End of Life Version A.2.
- **Survey of Health, Ageing and Retirement in Europe (SHARE):** Harmonized SHARE Version G and Harmonized SHARE End of Life Version G.
- **China Health and Retirement Longitudinal Study (CHARLS):** Harmonized CHARLS Version D2 and Harmonized CHARLS End of Life Version A.

Obtain each resource through its official custodian or authorised data-access portal:

- HRS: <https://hrs.isr.umich.edu/data-products>
- ELSA / UK Data Service study 5050: <https://beta.ukdataservice.ac.uk/datacatalogue/studies/study?id=5050>
- SHARE: <https://share-eric.eu/data/data-access>
- CHARLS: <http://charls.pku.edu.cn/en>
- Gateway harmonised resources: <https://g2aging.org/>

Access may require registration, an approved application, a data-use agreement, or other custodian conditions. Users are responsible for checking the current terms, citing the resources as required, and preventing onward redistribution. The authors cannot provide the individual-level data through GitHub or by email.

The code repository is intended to support transparent reuse of the analysis workflow. It does not itself provide data access, permission to combine releases, or permission to redistribute any source files.
